# Список покупок — Реліз v72 (PWA / Офлайн)

Повноцінний веб-додаток (PWA) для ведення списків покупок та каталогу товарів із підтримкою роботи без інтернету та встановлення на робочий стіл / головний екран через Google Chrome.

## Вміст архіву
- `index.html` — головний файл додатку (реліз v72)
- `manifest.json` — маніфест PWA для встановлення ярлика на пристрій
- `sw.js` — Service Worker для кешування ресурсів та повної роботи без інтернету
- `icon-192.png`, `icon-512.png`, `icon.svg` — іконки додатку для Chrome, Android, iOS та ПК

## Розгортання на GitHub Pages
1. Завантажте **всі файли** з цього архіву (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon.svg`, `README.md`) у корінь вашого GitHub-репозиторію.
2. Перейдіть у **Settings → Pages** репозиторію.
3. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main` та папку `/ (root)`, натисніть **Save**.
4. Відкрийте посилання `https://<ваш-логін>.github.io/<назва-репозиторію>/` у **Google Chrome**:
   - **На смартфоні (Android):** натисніть меню `⋮` → **«Додати на головний екран» / «Установити додаток»**.
   - **На комп'ютері (Windows/Mac/Linux):** натисніть іконку встановлення `⊕` у правому краю адресного рядка Chrome → **«Установити»**.
5. Після першого відкриття всі файли кешуються у `sw.js`, і додаток повністю працює **без підключення до інтернету**, зберігаючи всі ваші списки локально в пам'яті пристрою.
